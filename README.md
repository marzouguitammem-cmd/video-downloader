# محمّل الفيديو

تطبيق Android بسيط: تلصق رابط من **أي موقع**، تختار **فيديو MP4** أو **صوت MP3**، ويتحمّل الملف في `Download/محمّل الفيديو`.

- **فيديوهات من أي موقع**: تيكتوك، يوتيوب، فيسبوك، إنستغرام، وآلاف المواقع الأخرى (أي صفحة فيها فيديو يعرفها yt-dlp).
- **روابط الملفات** تتحفظ كيف ما هي: PDF، Word، PowerPoint، Excel، صور، zip…
- **المتصفّح داخل التطبيق** (القائمة ← «المتصفّح»): للمواقع الي ترفض التحميل المباشر. تحلّ الصفحة، تشغّل الفيديو، ويطلعلك زرّ «تحميل الفيديو». يلقط زادة الملفات الي تضغط على «تحميل» متاعها في الصفحة.
- **Google Drive / Google Docs / Dropbox**: رابط المشاركة يكفي (Docs → .docx، Slides → .pptx، Sheets → .xlsx). الملف لازم يكون «أي شخص عندو الرابط».

- فيديوهات تيكتوك تتحمّل **بلا العلامة المائيّة** كي تكون النسخة النظيفة متوفّرة.
- تنجم تختار الجودة: أفضل جودة، 720p، ولا 480p (أصغر حجمًا).
- **منشورات الصور في تيكتوك** (diaporama): الصور تتحفظ كلّها + الموسيقى MP3.
- **إنستغرام**: reels، فيديوهات، صور، ومنشورات فيها برشا صور/فيديوهات (carrousel) — كل حاجة تتحفظ.
- **فيسبوك**: فيديوهات، reels، وروابط المشاركة (`facebook.com/share/…`، `fb.watch/…`).
- المنشورات الي الموقع ما يعطيهاش كان للحسابات المسجّلة: القائمة ← «الحسابات» ← تيكتوك / إنستغرام / فيسبوك (مرّة وحدة؛ الـ cookies تبقى في التليفون برك).
- من أي تطبيق فيهم: «مشاركة» ← «محمّل الفيديو»، والرابط يتحطّ وحدو.
- التحميل يكمل حتى كي تخرج من التطبيق (إشعار فيه نسبة التقدّم).
- المحرّك (yt-dlp) يتحدّث وحدو، وفيه زرّ «تحديث المحرّك» في القائمة.

## التحميل

ادخل لصفحة **Releases** وحمّل `video-downloader-arm64.apk` (أغلب التليفونات).
إذا التليفون قال «غير متوافق»، حمّل `video-downloader-arm32.apk`.

كل تعديل يترفع على `main` يبني نسخة جديدة وحدو، وتتثبّت فوق القديمة.

## للمطوّر

- Kotlin + Material 3، `minSdk 26`.
- التحميل بـ [youtubedl-android](https://github.com/yausername/youtubedl-android) (Python + yt-dlp + ffmpeg داخل التطبيق).
- `.github/workflows/build-apk.yml` يبني الـ APK على GitHub وينشرو في Releases.
